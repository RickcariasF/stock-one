# Guía para editar el catálogo

Con el editor agregas, cambias o quitas productos desde tu computadora. Nada cambia en la tienda
hasta que presionas **Publicar**.

## Abrir el editor

1. Abre la carpeta `Documentos\stock-one`.
2. Haz doble clic en `StockOne-Editor.bat`. Se abre una ventana negra y luego tu navegador.
3. Deja la ventana negra abierta mientras trabajas. Al cerrarla, el editor se apaga.

## Antes de empezar

Presiona **Actualizar** para traer la última versión.

## Marcas

Cada producto pertenece a una marca, como NUMERIS o Nike. En la tienda, las marcas son el filtro
principal. Aparecen las que tienen productos visibles y las marcadas como **Próximamente**.

| Quiero... | Haz esto |
| --- | --- |
| Agregar una marca | Pestaña **Marcas** > **Agregar marca** |
| Corregir el nombre | Haz clic en la marca, cámbialo y presiona **Guardar**. Sus productos se actualizan solos |
| Eliminar una marca | Primero cambia de marca sus productos. Una marca con productos no se puede eliminar |
| Crear una marca mientras agregas un producto | En el formulario del producto, presiona **Nueva marca** |
| Anunciar una marca que aún no vendes | Abre la marca y marca **Próximamente**. En la tienda muestra el aviso y oculta sus productos |
| Lanzar esa marca | Abre la marca, desmarca **Próximamente** y publica |

No se pueden repetir nombres: "Nike" y "NIKE" son la misma marca.

## Productos

| Quiero... | Haz esto |
| --- | --- |
| Agregar un producto | **Agregar producto**, elige la marca, llena los datos y presiona **Guardar** |
| Cambiar un producto | Haz clic en el producto, cámbialo y presiona **Guardar** |
| Cambiar las existencias | Cambia **Existencias**. En 0 se muestra como agotado y el botón pregunta por disponibilidad |
| Marcarlo agotado sin tocar las existencias | En **Estado** elige **Agotado** |
| Esconderlo un tiempo | En **Estado** elige **Oculto** |
| Eliminarlo | Abre el producto y presiona **Eliminar** |
| Ponerlo primero | Marca **Destacar en la tienda**. Se muestra más grande |

Sobre las fotos:

- Sirven JPG, PNG o WebP de hasta 10 MB. Las fotos HEIC del iPhone se convierten primero a JPG.
- Admite hasta 8 fotos. Con 2 o más, la página del producto muestra un carrusel.
- La primera foto es la principal (dice **Principal**). Usa las flechas ‹ › de cada foto para ordenarlas.
- El editor las reduce y borra datos ocultos, como la ubicación donde se tomaron.

## Revisar y publicar

1. Presiona **Vista previa** y abre el enlace para ver la tienda con tus cambios.
2. Presiona **Publicar** y confirma.
3. Espera el aviso **Publicado**. Suele tardar 2 o 3 minutos.

Si te equivocaste antes de publicar, **Descartar cambios** devuelve todo a la última versión
publicada. Esa acción no se puede deshacer.

## Si algo falla

| Mensaje | Qué hacer |
| --- | --- |
| Tienes cambios sin publicar | Publícalos o descártalos, y luego presiona **Actualizar** |
| Tus cambios chocan con otros más recientes | No sigas editando. Avisa a quien administra el proyecto |
| GitHub rechazó el envío | Revisa tu internet y prueba de nuevo. Si sigue, tu sesión de GitHub venció |
| La tienda aún no muestra los cambios | Avisa a quien administra el proyecto para revisar el despliegue |
| El editor ya está abierto | Cierra la otra ventana negra y abre el editor de nuevo |
